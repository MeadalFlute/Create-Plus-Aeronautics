# Create Plus Aeronautics

A Minecraft modpack centered around Create mechanical gameplay and aeronautics expansion.

The custom scripts and configurations in this repository are for learning and modpack development purposes only. Third-party mods and their assets belong to their respective authors.

## Repository Contents

- KubeJS scripts
- FTB Quests configurations
- Custom resources and datapack content

## What is Not Included

This repository does not distribute third-party mod JAR files. Please obtain dependencies from CurseForge, Modrinth, or their respective mod pages.

You can also download the modpack ZIP from the Releases page and install it quickly via a launcher.

## Current Status

Under development.
