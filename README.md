# Create Plus Aeronautics

一个以 Create 机械玩法和航空扩展为核心的 Minecraft 整合包项目。

本仓库中的自写脚本与配置仅用于学习和整合包开发记录，第三方模组及其资源版权归原作者所有。

## 仓库内容

本仓库主要包含：

- KubeJS 脚本
- FTB Quests 任务配置
- 自定义资源与数据包内容

## 不包含内容

本仓库不直接分发第三方模组 jar 文件。请通过 CurseForge、Modrinth 或对应模组页面获取依赖。

也可通过 release 获取 zip 文件，通过启动器快速安装。
